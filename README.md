# 🌤️ Responsive Weather Dashboard

A sleek, modern weather dashboard built with vanilla JavaScript, HTML5, and CSS3. It fetches real-time weather metrics using the OpenWeatherMap API and features a custom glassmorphism visual design with responsive mesh gradient backgrounds.

## ✨ Features

* **Real-Time Data Fetching:** Displays current temperature, weather conditions, humidity, and wind speed for searched cities worldwide.
* **Responsive Layout:** Optimized for desktop screens, tablets, and mobile devices.
* **Glassmorphism UI:** Features modern frosted glass containers layered over dynamic CSS mesh gradient backgrounds.
* **Error Handling:** Gracefully handles invalid city searches or network errors with user-friendly alerts.
* **Asynchronous JavaScript:** Built using modern `async/await` syntax for seamless API interactions without page reloads.

---

## 🛠️ Built With

* **Markup:** Semantic HTML5
* **Styling:** CSS3 (Flexbox, CSS Variables, Glassmorphism, Custom Mesh Gradients)
* **Scripting:** JavaScript (ES6+, Fetch API, DOM Manipulation)
* **API:** [OpenWeatherMap API](https://openweathermap.org/api)
* **Icons:** [Remix Icon CDN](https://remixicon.com/)
